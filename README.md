# Haven-Homes

Landing page de uma imobiliária fictícia desenvolvida com HTML e CSS.

O projeto foi criado como parte dos meus estudos em desenvolvimento web, com foco em estrutura HTML, estilização com CSS, responsividade e criação de uma interface moderna.

#  Sobre o projeto

A Haven Homes é uma imobiliária fictícia criada para este projeto.

A página apresenta:

- Página inicial com seção Hero
- Apresentação da empresa
- Benefícios
- Imóveis em destaque
- Depoimentos de clientes
- Seção de contato
- Footer com informações da empresa
- Layout responsivo para diferentes tamanhos de tela

#  Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts
- GitHub Pages

#  Responsividade

O projeto foi desenvolvido para funcionar em:

-  Desktop
-  Tablets
-  Smartphones

#  Objetivo

Este projeto faz parte da minha evolução nos estudos de desenvolvimento web e foi criado para praticar a construção de landing pages modernas utilizando HTML e CSS.
